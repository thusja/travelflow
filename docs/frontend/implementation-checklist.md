# Frontend Implementation Checklist

목적: 프론트 기능 개발 시 PR 전에 빠르게 누락을 점검한다.

## 1. 라우팅/접근제어

- [ ] 신규 페이지 라우트 등록 및 lazy import 적용
- [ ] private 라우트 접근 가드 확인
- [ ] 잘못된 경로 진입 시 UX(리다이렉트 또는 안내) 확인

## 2. 데이터 연동

- [ ] API 호출이 공통 클라이언트를 통과하는지 확인
- [ ] Query key가 표준 포맷을 따르는지 확인
- [ ] mutation 후 invalidate 대상이 정의되었는지 확인

## 3. 상태/UI

- [ ] loading/empty/error 상태 처리 구현
- [ ] 제출 버튼 중복 클릭 방지
- [ ] 폼 검증 메시지가 사용자 친화적인지 확인

## 4. 인증/세션

- [ ] 401 발생 시 refresh 단일 큐 동작 확인
- [ ] refresh 실패 시 공통 로그아웃 이벤트 처리 확인
- [ ] 로그인/로그아웃 후 화면 상태 동기화 확인

## 5. 반응형/접근성

- [ ] 모바일(<=767)에서 레이아웃 깨짐 없음
- [ ] 키보드 포커스 이동 가능
- [ ] 아이콘 버튼에 라벨 또는 대체 텍스트 제공
- [ ] 색 대비 기준(텍스트 4.5:1) 확인

## 6. 품질 게이트

- [ ] `npm run lint` 통과
- [ ] 주요 페이지 수동 스모크(홈/패키지/예약/플래너/제안) 통과
- [ ] 콘솔 에러/경고 없음
- [ ] 더미 데이터 잔존 여부 점검

## 7. 문서 동기화

- [ ] API 계약 변경 시 상위 `docs/api-spec.md` 갱신
- [ ] 페이지 구조 변경 시 `page-spec.md` 갱신
- [ ] UI 규칙 변경 시 `ui-system.md` 갱신
